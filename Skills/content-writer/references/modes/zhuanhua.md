# `zhuanhua` 主模式

## 目标

先帮助观众解决一个具体问题，再在 Context Pack 明确支持时自然承接一个获准动作。删掉最后动作后，前文仍应值得听。

## 两种进入方式

- 价值先行：题目清楚时，开头直接给判断、做法或选择顺序，再解释原因；
- 场景先行：人物的动作、选择或犹豫直接产生当前卡点，后文继续沿同一选择推进。

场景只是包装、会让观众回想前文，或直接判断已经更清楚时，选价值先行。场景先行仍必须服从 Profile 的关系边界。

## 先交付价值

- 一次只解决一个具体问题，给出一个听众能复述的判断或做法；
- 不先铺行业意义、身份介绍、抽象情绪或销售承诺；
- 不把正文写成广告，也不只剩态度和动作；
- 专业提醒只保留理解当前判断所必需的部分，不能抢走主问题。

## 动作边界

- 只有 Context Pack 明确包含获准动作时，才在正文讲清以后使用一次；
- 不改变动作、渠道、适用范围或承诺，不增加第二动作；
- P4 当前 Context Pack 没有明确动作合同时，自然结束；不得自行添加关注、评论、私信、咨询、领取、预约、免费、名额或倒计时；
- 不用恐惧、羞辱、疾病焦虑、假稀缺或保证结果催促行动。
