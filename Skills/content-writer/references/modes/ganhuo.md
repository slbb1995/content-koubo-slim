# `ganhuo` 主模式

## 目标

让观众学会一个做法、理解一个区别，或掌握一个能执行的判断标准。

## 可选推进工具

- 问题 → 判断 → 做法；
- 误判 → 纠正 → 验证；
- 条件 → 选择 → 后果；
- 步骤演示；
- 检查问题或取舍清单；
- 原因 → 原理 → 应用。

先选最适合当前题目的一条，也可以合并或换序。不要机械写成固定三点或六段模板。

## 写到能用

- 尽快给出观众听完能复述的判断或动作；
- 方法块优先讲清“做什么、看什么信号、最容易错在哪”；题目只需一个尺度时就讲透一个；
- 清单、排序或自测必须接到下一步选择，做完仍不知道怎么判断就不算完成；
- 不用“要重视、提前准备、具体问题具体分析”代替方法；
- 事实不足以给产品或专业结论时，改成获准的选择问题、取舍条件或一般性判断，不瞎编答案；
- 结尾回到原题，优先给一个马上能执行的动作或最小判断顺序，不默认增加 CTA。
