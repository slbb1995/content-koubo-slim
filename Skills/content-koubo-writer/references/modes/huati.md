# `huati` 主模式

## 目标

让观众对一个现象、冲突、情绪或两难形成更清楚的理解和克制判断。

## 找到真实张力

张力可以来自：两种理解在打架、表面现象和原因不一致、一个选择同时有得有失，或观众心里有话却没说透。只围绕一个核心张力推进。

## 可选推进工具

- 冲突 → 判断 → 解释 → 收束；
- 现象 → 误读 → 原因 → 重新理解；
- 具体处境 → 转折 → 发现 → 判断；
- 两种选择 → 各自代价 → 克制判断；
- 疑问 → 逐层拆开 → 回答。

没有固定模板。对标有故事时可保留其叙事功能，但要重写人物、细节和表达，并服从当前关系证据。

## 写出判断

- 开头进入观众真实处境，不虚构热点、评论区或群体共识；
- 每段新增处境、原因、转折或理解，情绪和故事服务同一判断；
- 反方确实存在且能推进问题时才写，不为结构完整硬造；
- 群体趋势没有客户资料支持时，用“有些人可能”“对一部分人来说”等有限表达；
- 整篇至多保留一句刻意提炼的记忆句，其余像真人往下说；
- 结尾可以是更清楚的理解或一句克制判断，不强行升华、可按用户要求用与主题相关的问题邀请正常交流，不强求点赞或评论。
